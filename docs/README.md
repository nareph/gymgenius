# Welcome

Welcome to the official documentation of **GymGenius v3**.

GymGenius is not simply a workout generator or calorie tracker.

It is designed as a **Local-First AI Health Coach** capable of continuously analyzing a user's fitness journey to provide personalized recommendations for training, nutrition, recovery, and long-term progress.

Unlike traditional fitness applications that generate static workout plans, GymGenius continuously adapts its recommendations based on real user data while keeping all core functionality available offline.

The long-term vision is to build an intelligent health operating system that answers one simple question every day:

> **"Considering everything I know about this user today, what is the single best action that will move them closer to their goal?"**

---

# Vision

GymGenius aims to become an intelligent personal coach capable of combining multiple areas of expertise into a single adaptive system:

* Workout Programming
* Nutrition Coaching
* Recovery Optimization
* Progress Analysis
* Behavioral Guidance
* AI-Assisted Health Recommendations

Rather than treating these domains independently, GymGenius combines them through a central decision engine that evaluates the user's complete health profile before making recommendations.

---

# Core Principles

The entire project is built around six architectural principles.

## Local First

The application functions completely offline.

User data always belongs to the user and remains stored locally by default.

Cloud services are optional enhancements rather than mandatory dependencies.

---

## Deterministic Intelligence

Business decisions are computed using deterministic algorithms based on evidence-based fitness principles.

Artificial Intelligence enhances communication and personalization but never replaces core decision logic.

---

## Explainable AI

Every recommendation generated by GymGenius must include an understandable explanation.

Users should always know:

* what changed
* why it changed
* which data influenced the decision

---

## Modular Architecture

Every major domain is implemented as an independent engine.

* Workout Engine
* Nutrition Engine
* Recovery Engine
* Progress Engine
* Decision Engine

Each module can evolve independently while remaining coordinated through the Decision Engine.

---

## Evidence-Based Fitness

Recommendations are grounded in established sports science principles, including:

* Progressive overload
* Recovery management
* Energy balance
* Nutrition fundamentals
* Training consistency
* Sustainable habit formation

---

## Long-Term Personalization

GymGenius continuously learns from historical data.

The longer the application is used, the more personalized its recommendations become.

# Design Philosophy

GymGenius follows a layered architecture in which every component has a single responsibility.

```text
Presentation Layer
        ↓
State Management
        ↓
Repositories
        ↓
Business Services
        ↓
Domain Engines
        ↓
Decision Engine
        ↓
AI Coach
        ↓
Local Storage
```

This separation ensures scalability, maintainability, and testability while allowing each subsystem to evolve independently.
