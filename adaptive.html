Générateur de fond adaptatif

Pour les icônes Android de GymGenius

Instructions

  1. Sélectionnez une couleur de fond qui correspond à votre thème d'application
  2. Téléchargez l'image de fond générée
  3. Placez-la dans le dossier assets/launcher_icon/ sous le nom adaptive_background.png
  4. Mettez à jour votre configuration flutter_launcher_icons dans pubspec.yaml
  5. Exécutez flutter pub run flutter_launcher_icons:main
